# Training data and policy integration

Download HDF5 demonstrations from [LIBERO-Pro2.0-Train](https://huggingface.co/datasets/zhouxueyang/LIBERO-Pro2.0-Train). Simulator assets, BDDL and initial states come from the separate [evaluation repository](https://huggingface.co/datasets/zhouxueyang/LIBERO-Pro2.0-Eval).

Each `data/<suite>/task_<id>/<case>/` contains `episodes.hdf5`, `metadata.json` and `source_index.json`. An HDF5 file contains `data/demo_0` through `data/demo_29`: relative 7D `actions`, scene/wrist RGB frames at 128×128, proprioception, rewards and termination flags. Read the [schema and provenance](https://huggingface.co/datasets/zhouxueyang/LIBERO-Pro2.0-Train/blob/main/docs/data_format.md) before adapting a loader.

Demonstrations were generated by a privileged-state oracle, not human teleoperation. There are 40,470 stored demonstrations but 37,396 unique source trajectories; 106 instances contain declared copies. The JSONL episode index provides `keep_without_declared_fanout`. Keep all related trajectories within the training partition and follow `assets/benchmark_split_v1.json`; held-out task definitions are not training demonstrations.

For a VLA or WAM policy, use its official training code, action normalization, camera conventions and checkpoint. Adapt the HDF5 loader to its expected tensors; the benchmark does not supply a universal training entry point for all policies.

The upstream LIBERO behavioral-cloning and lifelong-learning code is retained in `simulator-source/libero/lifelong/`, with Hydra configurations in `simulator-source/libero/configs/` and CLI entry points `lifelong.main` / `lifelong.eval`. These retain the original benchmark/per-task dataset loader, which does not automatically consume the released per-instance training tree. Configure or convert that layout explicitly instead of passing the directory unchanged. Dataset inspection and conversion helpers are in `simulator-source/scripts/`.

Evaluate trained policies with an adapter and `--split test`; retain each policy's official action horizon, preprocessing, control convention and suite-specific episode limits. See [the evaluation guide](remote-evaluation-guide.md).
